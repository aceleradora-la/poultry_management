# Ícono del Módulo

Este directorio contiene el ícono del módulo Poultry Management.

## Archivos

- `icon.svg` - Ícono en formato SVG (vectorial, escalable)
- `icon.png` - Ícono en formato PNG (128x128 px) - **Recomendado para Odoo**
- `index.html` - Descripción extendida del módulo

## Nota

Odoo prefiere íconos en formato PNG. Si solo tienes `icon.svg`, conviértelo a PNG:

1. Usa una herramienta online: https://cloudconvert.com/svg-to-png
2. Tamaño: 128x128 píxeles
3. Guarda como `icon.png` en esta carpeta

El manifest buscará ambos formatos, pero PNG es el preferido.
